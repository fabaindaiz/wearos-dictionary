# Proposal: same-answer-or-refuse

A script that reimplements a product rule to explain or measure its output disagrees with the product even after its obvious defect is fixed; the residual disagreement is part of the result and is reported with it, or the product's own function is called instead.

## Evidence

One carrier, a second occurrence after the one this note already records from it. To explain why many records were left out of a classification, the agent replicated the classification rules in a separate script and compared it with the shipped data. It first disagreed on about one row in six, because it read a key the source does not have; after the fix it still disagreed on about one row in sixty, and the breakdown was reported to the owner with that residual stated but not explained. The product's own classification function was not called. Literature: the note's own.
