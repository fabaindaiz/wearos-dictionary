# Proposal: cleanup-belongs-to-the-supervisor

A probe's own restore can fail before the probe runs, not only after: a backup written to a path that does not exist leaves nothing to restore, so the supervisor checks the backup exists before starting the child and compares the state after.

## Evidence

One carrier, one occurrence. A mutation probe copied the file under test to a backup path whose directory did not exist; the copy failed, the probe ran, and its own restore step had nothing to restore, leaving the mutant in the source. The next run of the suite caught it and it was restored by hand. This carrier's audit already fails on a marked probe left behind; the mutant here carried its marker, which is why it was found. Literature: the note's own.
