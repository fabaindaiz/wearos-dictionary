In a pipeline that curates third-party content, three kinds of removal need three standards: garbage (rows the extraction produced that the source never said) is removed on correctness alone and gets a check; duplication is removed only if no query loses its answer; shrinking (true rows nothing else answers) has no justification without a stated budget. Without the line, a curated artefact drifts by attention, losing whatever happened to be measured that day.

## Evidence

One repository: the agent offered to remove a few percent of true, correct index entries in the same list as genuine extraction garbage; the human asked how to separate cleaning from arbitrary reduction, and the proposal was withdrawn. An earlier decision had retired the size budget because it never changed a decision, so no budget existed to weigh the removal against.
