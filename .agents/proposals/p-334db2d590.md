A boundary for removal rules: a data-cleaning rule evaluated against a hand-written list of known-good items reports that nothing good was lost for everything the list omits. Its coverage is the list of items it removes, read item by item, not a count against the list.

## Evidence

One repository, one day: a rule that would have deleted the translations of two very common function words passed the comparison because the hand list lacked them; printing which headwords each rule hits found it, and the same reading killed two wider rules (each removing thousands of keys, among them real acronyms and real translations) and two more later that day. Earlier the same week, a rule to keep entries that carry content counted non-empty fields and kept entries whose only content was in a language the artefact does not declare; rendering real entries showed it, the counts did not.
