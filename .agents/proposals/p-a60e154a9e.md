An enforcer audit that accepts any named path counts a rule as enforced when the rule names the file holding the value; a file does not check its own contents, so the value can change to exactly what the rule forbids with no failure. Overlaps principle 1.

## Evidence

One repository: a pinned-version decision named the version catalogue as its enforcer; the version was then raised to the one the decision rejected by name, and the rules-without-enforcer check still counted the row as enforced. Fixed by a check that compares the decision's pin with the catalogue's value.
