# Proposal: report-coverage-before-findings

A count or a verifier that reads only part of its input reports a clean or plausible result; the coverage line is what exposes it. A per-run "not found" or "evaluated N of M" counter is the cheapest form, and a verifier that samples a fixed number of items states that it sampled.

## Evidence

One carrier, two occurrences in a month. A count that read each source line only up to a fixed prefix length missed most of one language's source; only the script's own count of rows not found, about one in twenty of the rows, gave it away, and the second run parsed every line. Separately, a data verifier that samples a fixed small number of payloads per artefact let a few hundred empty records ship over several builds; a later rebuild exposed them through another check.
