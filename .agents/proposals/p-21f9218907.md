A route the note does not name: committing with an explicit path list does not pick up a new untracked file, so the commit lacks what the working tree has and the working tree's gate cannot see the difference.

## Evidence

One repository: a new function was committed without its new test file; the gate stayed green because the file was on disk, and a status listing two commits later caught it. A clean worktree of the commit, which the repository's own procedure asks for and which was skipped that time, would have reported a handful fewer tests.
