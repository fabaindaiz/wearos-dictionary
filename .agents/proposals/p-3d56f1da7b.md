A new form: a measurement script that reimplements the production rule is a second path to the answer, and it measures a different rule. Measure by calling the repository's own function.

## Evidence

One repository, one session, twice: reimplementing a vocabulary selection by its obvious sort key estimated a coverage loss of tens of points where the real function, which orders by a frequency signal first, gave zero; decompressing with the raw library instead of the codec's own function missed a parameter and, behind a bare exception handler, reported zero. Each was found only because the result was checked against the real function.
