# Palabras que un diccionario de español TIENE que poder encontrar.
#
# Es el mismo patrón que `normalization-vectors.tsv`: el archivo de expectativas ES el
# mecanismo. `verify_pack.py` lo corre solo cuando el pack declara `es`, y falla nombrando las
# que faltan.
#
# ⚠️ **Lo que esto NO resuelve, y hay que decirlo.** Una lista escrita a mano tiene el mismo
# sesgo que mirar a mano: no sabe lo que nadie pensó en poner. Sirve contra **regresiones** —una
# poda que se lleva medio calendario, un filtro que vacía el 39,6 % de las entradas— y no contra
# huecos desconocidos. Para eso no hay atajo.
#
# ⚠️ **Agregar una palabra acá es documentar una decisión de producto**, no engordar un test:
# afirma que este diccionario, sin ella, está roto. Por eso van agrupadas y por eso cada grupo
# dice qué defiende.
#
# Una palabra cuenta como encontrada si es un lema del pack **o** una de sus formas flexionadas:
# `fui` llega a `ir`, y eso es exactamente lo que el usuario experimenta al buscarla.
